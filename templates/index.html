How SkyGuard Works

🌐

Live Data Ingestion

Continuously ingests real-time atmospheric data from Open-Meteo API across 6 major Indian cities, storing in MongoDB Atlas.

🧠

Isolation Forest ML

Trained Isolation Forest model detects atmospheric anomalies — temperature spikes, pressure drops, humidity inconsistencies.

🔍

XAI Explainability

Every anomaly alert comes with SHAP & LIME explanations — pinpointing exactly which sensor caused the alarm and why.

🚨

Severity Grading

Four-tier severity system (NORMAL → ELEVATED → WARNING → CRITICAL) with specific anomaly type classification.
